# Roadmap

These are development directions, not delivered features or dated commitments.

| Planned Area | Intended Direction |
| :--- | :--- |
| Ableton | Deeper application integration beyond current process telemetry and external MIDI workflows |
| Push 3 | Device-specific expansions and creative workflows |
| Synesthesia | Live music-synced visualization integration |
| Stream Deck | Possible controller actions and coordinated workflows |
| Xbox Controller | Possible game-controller input workflows |
| Routing | Further rule/macro tooling around the existing CC-triggered sequence engine |

The release foundation comes first: compatible distribution licenses, reliable packaging, clear documentation and testing on another Windows PC.
